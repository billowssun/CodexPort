CPCodexPort
适用情况 怎么迁移 安全边界 GitHub

开源 · Windows · 多设备迁移

迁移、合并
多台设备的
Codex 聊天。

把一台设备上的聊天包导入另一台设备。保留本机记录，补齐缺失聊天，并迁移附件、标题和状态。

下载 v1.2.0 ↓ 查看源代码 ↗

适用于

  • 更换设备
  • 系统重装
  • 多地点使用
  • 聊天归档与恢复

迁移只需要两步

来源设备导出，目标设备导入。

  1. 01

    来源设备

    点击“导出聊天包”

    Codex 自动关闭，完成逐项校验后把聊天包保存到桌面。

  2. 02

    目标设备

    点击“导入聊天包”

    选择聊天包后增量导入，完成后自动启动 Codex。需要迁移到更多设备时，继续导入同一个聊天包。

迁移聊天，
不迁移环境。

完全相同的聊天自动跳过；同一聊天存在不同版本时保留双方。聊天包可通过 U 盘、局域网或自己的网盘传输。

会迁移与合并

  • 活跃和已归档聊天
  • 标题、置顶、归档状态与索引
  • 附件、生成图片与目标状态

不会带走

  • 账号、登录状态和 API 密钥
  • 配置、插件、技能与规则
  • 自动化与记忆
导入前自动备份包内文件逐项校验失败自动恢复不是云端实时同步

让每台设备，都能接上已有上下文。
