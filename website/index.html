唯一需要记住的流程

旧电脑一次，新电脑一次。

  1. 01

    旧电脑

    点击“导出聊天”

    软件发现 Codex 正在运行时会自动关闭，并生成一个迁移包。

  2. 02

    新电脑

    点击“导入聊天”

    选择迁移包后自动还原记录，完成后自动启动 Codex。

边界清楚，迁移才安心

只带走聊天。

迁移包是本地文件。你可以用 U 盘、局域网或自己的网盘传到新电脑。

会迁移

  • Codex 聊天记录
  • 聊天所需的本地索引
  • 迁移包完整性校验信息

不会迁移

  • 账号和登录状态
  • API 密钥和认证信息
  • Codex 配置与偏好

新电脑不必从空白开始
