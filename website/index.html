每次合并仍然只有两步

一台导出，另一台导入。

  1. 01

    来源电脑

    点击“导出聊天包”

    Codex 会自动关闭，经过校验的聊天包会保存到桌面。

  2. 02

    目标电脑

    点击“导入聊天包”

    选择聊天包后增量合并，完成后自动启动 Codex。想让两台电脑都有合集，再反向操作一次。

合并聊天，
不碰配置。

完全相同的聊天会跳过；同一聊天出现不同版本时保留两份，不静默覆盖。聊天包可通过 U 盘、局域网或自己的网盘传输。

会合并

  • 活跃和已归档聊天
  • 标题、置顶、归档状态与索引
  • 附件、生成图片与目标状态

不会带走

  • 账号、登录状态和 API 密钥
  • 配置、插件、技能与规则
  • 自动化与记忆
导入前自动备份包内文件逐项校验失败自动恢复
